# LetsConnect 🌐

A modern full-stack social networking web application inspired by X (formerly Twitter). LetsConnect allows users to create accounts, share posts, engage with community feeds, follow other creators, and interact in real-time.

🔗 **Live Demo:** [lletsconnect.netlify.app](https://lletsconnect.netlify.app)

---

## ✨ Features

- **Authentication & Security:** Secure user signup, login, and logout using JWT and cookie-based session handling.
- **Feed & Posts:** Create, read, like, comment, and repost updates.
- **User Profiles:** Customizable profiles displaying bio, user posts, and follower counts.
- **Follow System:** Follow and unfollow users to customize your personalized feed.
- **Responsive UI:** Fully responsive design optimized for mobile, tablet, and desktop viewports.

---

## 🛠️ Tech Stack

### Frontend
- **Framework / Library:** React.js / JavaScript (ES6+)
- **Styling:** CSS3 / Tailwind CSS (or modular CSS)
- **Deployment:** [Netlify](https://lletsconnect.netlify.app)

### Backend
- **Runtime:** Node.js
- **Framework:** Express.js
- **Database:** MongoDB & Mongoose
- **Authentication:** JSON Web Tokens (JWT) & HTTP-only cookies
